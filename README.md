# Gemini Conversation Backup

ส่วนขยายสำหรับ Brave และเบราว์เซอร์ที่รองรับส่วนขยาย Chromium ใช้สำรองบทสนทนาที่เปิดอยู่บน `gemini.google.com` เป็นไฟล์ HTML โดยพยายามบันทึกเฉพาะเนื้อหาที่ผู้ใช้คุยกับ Gemini และไม่รวมแถบด้านข้างหรือเมนูนำทาง

## ความสามารถ

- ใช้กับหน้า Gemini ที่เปิดอยู่ในแท็บปัจจุบัน
- เลื่อนหน้าไปด้านล่างเพื่อให้เนื้อหาที่โหลดเมื่อเลื่อนปรากฏ จากนั้นเลื่อนกลับขึ้นด้านบน
- ค้นหาข้อความฝั่งผู้ใช้และคำตอบของ Gemini แล้วเลือก container ที่ครอบคลุมบทสนทนา
- ตัดสคริปต์ iframe เมนูนำทาง แถบด้านข้าง ปุ่ม และช่องกรอกข้อความออกจากไฟล์ที่บันทึก
- บันทึก HTML เป็น UTF-8 เพื่อให้ภาษาไทยแสดงผลถูกต้อง
- แจ้งข้อผิดพลาดหากไม่พบองค์ประกอบบทสนทนา แทนการบันทึกหน้าเว็บทั้งหมดโดยไม่ตั้งใจ

> ส่วนขยายนี้บันทึกภาพนิ่งจากเนื้อหาที่แสดงอยู่ในหน้าเว็บ ไม่ได้ส่งออกประวัติจากระบบหรือเรียก API ของ Gemini

## ความต้องการ

- Brave หรือเบราว์เซอร์ Chromium ที่รองรับ Manifest V3
- เปิดหน้า Gemini ที่มีบทสนทนาซึ่งต้องการสำรอง และลงชื่อเข้าใช้หากจำเป็น
- หากต้องการสร้างไฟล์ ZIP ต้องมีคำสั่ง `zip` ในระบบ

## ติดตั้งใน Brave แบบ Load unpacked

1. ดาวน์โหลดหรือวางไฟล์โครงการนี้ไว้ในโฟลเดอร์บนเครื่อง
2. เปิด `brave://extensions` ใน Brave
3. เปิดสวิตช์ **Developer mode** (โหมดนักพัฒนาซอฟต์แวร์)
4. กด **Load unpacked** (โหลดส่วนขยายที่คลายแพ็กแล้ว)
5. เลือกโฟลเดอร์โครงการที่มี `manifest.json` อยู่โดยตรง ไม่ใช่เลือกไฟล์ ZIP หรือโฟลเดอร์ `dist`
6. เปิดบทสนทนาที่ต้องการสำรองบน `https://gemini.google.com/`
7. กดไอคอนส่วนขยาย แล้วเลือก **สำรองหน้านี้**
8. รอจนสถานะในหน้าต่างส่วนขยายแจ้งว่าเริ่มดาวน์โหลดแล้ว ไฟล์ HTML จะอยู่ในโฟลเดอร์ดาวน์โหลดที่ Brave ตั้งค่าไว้

หากไม่เห็นไอคอนส่วนขยาย อาจต้องกดปุ่มรูปชิ้นส่วนปริศนาในแถบเครื่องมือ แล้วปักหมุด **Gemini Conversation Backup** ไว้

## อัปเดตส่วนขยายที่ติดตั้งอยู่

หลังเปลี่ยนไฟล์ส่วนขยายหรือดาวน์โหลดรุ่นใหม่:

1. เปิด `brave://extensions`
2. กดปุ่ม **Reload** บนการ์ดของส่วนขยาย
3. กลับไปยังแท็บ Gemini แล้วลองสำรองอีกครั้ง

ถ้าหน้า Gemini เปิดค้างอยู่ก่อนอัปเดต ให้รีโหลดหน้า Gemini ด้วย เพื่อให้ส่วนขยายทำงานกับเอกสารหน้าเว็บที่โหลดใหม่

## สร้างไฟล์ ZIP

จากโฟลเดอร์โครงการ รัน:

```sh
./compile.sh
```

สคริปต์จะสร้างไฟล์:

```text
dist/GeminiConversationBackup.zip
```

ไฟล์ ZIP นี้ใช้สำหรับจัดเก็บหรือส่งต่อส่วนขยาย หากต้องการติดตั้งผ่าน **Load unpacked** ให้แตก ZIP ก่อน แล้วเลือกโฟลเดอร์ที่มี `manifest.json` อยู่โดยตรง

## ข้อจำกัดที่ควรทราบ

- โครงสร้างหน้า Gemini อาจเปลี่ยนแปลงได้ หากส่วนขยายไม่พบองค์ประกอบข้อความผู้ใช้และคำตอบ อาจต้องปรับตัวค้นหาให้ตรงกับหน้าเว็บรุ่นใหม่
- เนื้อหาบทสนทนาที่ Gemini ยังไม่ได้โหลดหรือไม่อยู่ในหน้าเว็บขณะสำรอง อาจไม่ถูกรวม แม้ส่วนขยายจะเลื่อนหน้าเพื่อช่วยโหลดเนื้อหาแล้วก็ตาม
- ไฟล์ HTML เป็นภาพนิ่งและนำสคริปต์ของหน้าเดิมออก จึงไม่สามารถโต้ตอบหรือทำงานเหมือนหน้า Gemini จริงได้
- รูปแบบบางส่วน รูปภาพ หรือทรัพยากรภายนอกอาจต้องเชื่อมต่ออินเทอร์เน็ต และอาจเปลี่ยนแปลงหรือไม่แสดงเมื่อเปิดไฟล์ในภายหลัง
- เนื้อหาที่ถูกซ่อน ยุบ หรือโหลดแบบเสมือน (virtualized) อาจไม่ปรากฏครบในไฟล์
- ส่วนขยายจะไม่บันทึกหน้าอื่น หากแท็บปัจจุบันไม่ได้เปิด `gemini.google.com`

## ความเป็นส่วนตัวและสิทธิ์

การสร้างไฟล์ทำในเบราว์เซอร์บนเครื่องของผู้ใช้ ส่วนขยายไม่ได้อัปโหลดบทสนทนาไปยังบริการอื่น ต้องใช้สิทธิ์ `activeTab`, `scripting` และ `downloads` เพื่ออ่านแท็บที่ผู้ใช้สั่งงาน เลื่อนและสร้าง snapshot ในหน้าเว็บ และเริ่มดาวน์โหลดไฟล์ตามลำดับ

## การแก้ปัญหา

### กดแล้วแจ้งว่าให้เปิดบทสนทนา Gemini

ตรวจสอบว่าแท็บที่กำลังเลือกเปิด `gemini.google.com` อยู่จริง จากนั้นกดไอคอนส่วนขยายจากแท็บนั้น

### แจ้งว่าไม่พบเนื้อหาบทสนทนา

รอให้ Gemini โหลดข้อความให้เสร็จ ตรวจสอบว่าหน้าแสดงทั้งข้อความที่ส่งและคำตอบ แล้วลองใหม่ หากยังไม่สำเร็จ หน้าเว็บอาจเปลี่ยนโครงสร้างจนตัวค้นหาของส่วนขยายไม่ตรงแล้ว

### ไฟล์ภาษาไทยแสดงเป็นอักขระผิด

ใช้ไฟล์ที่สร้างจากส่วนขยายรุ่นปัจจุบัน ซึ่งกำหนด charset เป็น UTF-8 แล้ว หากเปิดไฟล์จากสำเนาเก่า ให้สำรองบทสนทนาใหม่อีกครั้ง

### ไม่พบไฟล์ที่ดาวน์โหลด

ตรวจสอบรายการดาวน์โหลดของ Brave และโฟลเดอร์ดาวน์โหลดที่ตั้งค่าไว้ รวมถึงการแจ้งเตือนหรือการบล็อกการดาวน์โหลดของเบราว์เซอร์

## ไฟล์สำคัญในโครงการ

- `manifest.json` — ข้อมูลและสิทธิ์ของส่วนขยาย
- `background.js` — ติดต่อระหว่างหน้าต่างส่วนขยายกับแท็บที่เลือก
- `content.js` — เลื่อนหน้า ค้นหาและคัดลอกเนื้อหาบทสนทนา แล้วสร้างไฟล์ HTML
- `popup.html`, `popup.css`, `popup.js` — หน้าต่างควบคุมที่เปิดจากไอคอนส่วนขยาย
- `compile.sh` — สร้างไฟล์ ZIP สำหรับแจกจ่ายหรือจัดเก็บ
